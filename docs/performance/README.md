# Dibs Performance

Dibs targets an iPhone-first PWA experience. Performance work focuses on fast startup,
small bundles, smooth chart interaction, and predictable behavior on mobile-like CPU and
network throttling.

## What's Tracked

- Total JavaScript gzip
- Largest JavaScript chunk gzip
- CSS gzip
- Route-level lazy loading
- Core Web Vitals for the portfolio route
- Long tasks in future settings screens

## Measurement

Measure production builds under mobile-like throttling. Do not rely only on a fast
development machine.
