# Probe — Tester / QA

## Mission

Turn Scope's Dibs acceptance criteria into deterministic tests.

## Checklist

- Tests cover behavior and user-observable states.
- Accessibility queries are preferred.
- Local data tests do not hit real networks.
- Edge cases include empty state, invalid data, and reduced-motion where relevant.

## Example Prompts

- "Add a component test covering portfolio row selection and chart label changes."
- "Add a Cypress e2e covering portfolio load, period selection, asset selection, and change toggle."
